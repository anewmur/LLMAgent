# LLMAgent

ИИ-агент, который по JSON трассы подземного водопровода выпускает комплект документов:
общие данные, план трассы, продольный профиль и спецификацию, а также отчёт о проверках
и журнал вызовов инструментов. Оформление по ГОСТ Р 21.101-2026, ГОСТ 21.704-2011,
ГОСТ 21.110-2013 и ГОСТ 21.206-2012.

Геометрию, длины, отметки и количества считает программа. Модель только понимает запрос,
вызывает инструменты и пересказывает их результат.

## Установка

Нужен Python 3.10+. Команды для Windows PowerShell.

### Из wheel

```powershell
pip install llmagent-0.1.0-py3-none-any.whl
llmagent
```

Запускать из папки, где лежат `input/input.json` и ключ (см. ниже).

### Из репозитория

```powershell
git clone https://github.com/anewmur/LLMAgent.git
cd LLMAgent
pip install -e ".[dev]"
llmagent
pytest
```

## Ключ и модель

`input/`, `api_keys.env` и `output/` ищутся в текущей папке. Ключ берётся из переменной окружения
или из `api_keys.env`. Переменная окружения имеет более высокий приоритет.

Пример `api_keys.env` (две последние строки необязательны):

```
LLM_API_KEY=ваш_ключ
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
```

| Переменная | По умолчанию |
|---|---|
| `LLM_API_KEY` | обязательна |
| `LLM_BASE_URL` | `https://api.deepseek.com` |
| `LLM_MODEL` | `deepseek-flash` |

Подходит любой OpenAI-совместимый API. Модель и адрес печатаются при старте и пишутся в `tool_log.md`.
Комплект в репозитории сделан на `deepseek-flash`.

## Запуск

`llmagent` или `python main.py`. Другая трасса: `llmagent input/examples/alternate.json`.
При старте программа читает `input/input.json` и сразу выпускает комплект в `output/`.
Исходный JSON не меняется. Дальше вопросы вводятся в консоли, `выход` завершает работу.

Примеры запросов:

- `Выпусти комплект документов по трассе input/input.json`
- `Перемести конечную точку P5 на X = 300 м и обнови комплект`
- `Перемести P5 на Y = 100` — появляется поворот в P4. Агент предложит отвод и выпустит комплект после согласия.
- `Верни P5 на Y = 80 и убери отвод в P4`

## Результат

В `output/`:

- `general.svg`, `plan.svg`, `profile.svg`, `specification.svg` — листы A3
- `pdf/package.pdf` — все четыре листа
- `specification.csv`
- `check_report.md` — проверки, ГОСТ-таблица, принятые допущения, ограничения
- `changes.md` — что изменилось после правок
- `tool_log.md` — вызовы инструментов, время, токены и стоимость каждого вопроса

Комплект собирается во временной папке и заменяет `output/` только после успешных проверок.
Если правка отклонена, остаётся прежний комплект. Если нельзя выпустить сам проект
(например, нет отметки в точке), в `output/` остаётся только `check_report.md` с причиной.

`output/` хранится в Git: по ТЗ комплект сдаётся вместе с репозиторием.

## Инструменты агента

| Инструмент | Что делает                                                                   |
|---|------------------------------------------------------------------------------|
| `load_route(path)` | загружает трассу из папки `input/` и выпускает комплект                      |
| `release_documents()` | перевыпускает комплект                                                       |
| `update_point(name, x, y, ground, axis, bends)` | меняет точку. В `bends` можно добавить, изменить или убрать отвод (угол `0`) |
| `add_point`, `remove_point` | вставляет или удаляет точку                                                  |
| `add_bend`, `remove_bend` | добавляет или удаляет отвод                                                  |
| `update_pipe` | меняет данные трубы (материал, диаметр, толщина стенки )                                   |
| `change_profile_font` | меняет шрифт профиля на ступень                                              |

Любая правка проверяется целиком и сразу перевыпускает все четыре листа. Поворот трассы без отвода
блокирует правку, агент спрашивает, добавить ли отвод.

## Время и стоимость

Финальный прогон 10.11.2026, `deepseek-flash`, тариф вне пика:

| Запрос | Время, с | Стоимость, $ |
|---|---|---|
| Выпуск комплекта | 3,84 | 0,000371 |
| Перенос P5 на X = 300 м | 3,56 | 0,000185 |

Один выпуск занимает около 4 с и стоит меньше $0,001. Тарифы заданы в `agent/settings.py`.
Для другой модели время и токены считаются, а стоимость нет.

## Как устроено

- `main.py` — консольный диалог
- `agent/` — клиент LLM, системный промпт, описание инструментов, журнал
- `core/` — чтение и проверка трассы, расчёт, листы плана, профиля, спецификации и общих данных, выпуск
- `core/checks/` — проверки готовых листов
- `config/requirements.yaml` — состав документов, нормативные ссылки, допущения и ограничения
- `config/drawing_settings.py` — масштабы, линии, шрифты, отступы
- `templates/` — SVG-шаблоны листов и шаблон журнала
- `assets/fonts/` — DejaVu Sans, встраивается в PDF

Масштаб плана выбирается автоматически из ряда 1:500, 1:1000, 1:2000, 1:5000.
Основная трасса выходит в 1:1000, P5 на X = 400 м даёт 1:2000. Если трасса не помещается
на A3 даже в 1:5000, выпуск отклоняется. Профиль по горизонтали выбирается так же, по вертикали 1:100.

Подробнее: `docs/architecture.md`. Таблица «требование - пункт ГОСТ - где реализовано - как проверено» —
`docs/requirements_table.md`.

## Примеры входных данных

В `input/examples/`:

- `alternate.json` — другая трасса, 250 м, один отвод 90°
- `no_p3.json` — нет отметки оси в P3 (сценарий 3 ТЗ)
- `material_conflict.json` — «Сталь» в объекте, «ПЭ 100» у трубы (сценарий 4 ТЗ)
- `gost_b1.json` — профиль по рис. В.1 ГОСТ 21.704
- `thick*.json` — крупные диаметры, труба двумя линиями

## Допущения

Всё, чего нет во входных данных, не выдумывается, а записывается как допущение.
Полный список — в `output/check_report.md`. Ключевые выводятся на листе «Общие данные» и в ответе агента.
Например: обозначение сети В1 принято условно, материал и SDR отводов как у трубы,
изоляция не задана. Пропущенная отметка точки
не вычисляется по соседним, выпуск останавливается.

## Ограничения

Полный список — в `output/check_report.md`.

- Нет колодцев, камер, футляров и пересечений с другими сетями.
- Нет геологии, грунтовых вод, натурной поверхности и основания.
- В точке одна отметка оси, перепад на одной вертикали не поддерживается.
- Нет гидравлики, прочности, расходов и напоров.
- Только A3, спецификация на одном листе. DXF и схема напорной сети не выпускаются.
- Не все наложения подписей устраняются автоматически, сомнительные места попадают в отчёт как предупреждения.
- Блок «Принятые допущения» на листе «Общие данные» добавлен по требованию ТЗ. По ГОСТ Р 21.101 эти пункты относятся к общим указаниям. Заголовок «Учебный комплект» тоже не из ГОСТ.
