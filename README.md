# LLMAgent

## Как устроена задача (пояснение для проверяющего)

- Комплект НВ по ТЗ разд. 3: общие данные, план трассы, продольный профиль. Спецификация (обозначение .СО) прилагается к комплекту и записывается в ведомость ссылочных и прилагаемых документов (ГОСТ 21.110 п. 4.13). Отчёт о проверках — документ ТЗ, в комплект по ГОСТ не входит.
- Сеть состоит из участков. Участок — прямой отрезок между двумя соседними точками трассы (P0–P5). В точках поворота установлены отводы.
- План и профиль изображают одну и ту же трассу: длины, расстояния и номера точек на них совпадают.
- Количество трубы в спецификации (м) равно сумме длин участков и вычисляется программой.
- Каждый лист имеет основную надпись с обозначением документа.
- Изменение входных данных (например, перенос P5) ведёт к перевыпуску всех связанных документов (ГОСТ Р 21.101 п. 7.1.4).

## Основные понятия

- **Сеть (система) В…** — Наружная сеть водоснабжения с буквенно-цифровым обозначением (например, В1, В2) по ГОСТ 21.205.
- **Участок трубопровода** — Прямолинейный отрезок сети между двумя точками трассы. Свойства: длина, уклон, диаметр, отметки концов.
- **Точка трассы** — Характерная точка (P0–P5): начало и конец, точка разрыва или присоединения (марка Т), угол поворота (марка УП). Свойства: координаты, отметки.
- **Угол поворота (УП)** — Точка изменения направления трассы. Значение в градусах; на плане не подписывают, если угол 90°.
- **Труба / материал** — Изделие с наружным диаметром и толщиной стенки (⌀110×6.6), материалом ПЭ100 SDR17 и документом-стандартом.
- **Фасонная часть (отвод)** — Элемент трубопровода (отвод). УГО по 21.206 табл. 1; включается в спецификацию (PC-03).
- **Основной комплект НВ** — Основной комплект рабочих чертежей марки НВ (наружные сети водоснабжения).
- **Общие данные** — Первые листы комплекта: ведомости, условные обозначения, общие указания, основные показатели сети.
- **План сетей** — Чертёж трассы в плане (подосновы нет — см. limitations).
- **Продольный профиль** — Развёртка по оси трубопровода с поверхностью земли, трубой и сооружениями.
- **Сетка (таблица) профиля** — Таблица под профилем, боковик по форме 2 (подземная прокладка).
- **Спецификация СО** — Прилагаемый текстовый документ по форме 1 ГОСТ 21.110 с шифром «СО».
- **Позиция спецификации** — Строка спецификации: поз., наименование и техническая характеристика, тип/марка/документ, код, поставщик, ед. изм., кол., масса, примечание.
- **Лист** — Единица графического или текстового документа с основной надписью, форматом по ГОСТ 2.301 и номером.
- **Основная надпись** — Штамп листа (формы 3, 6) с графами: обозначение, наименования, стадия, лист/листов, формат.
- **Обозначение документа** — Базовое обозначение + «-НВ» (комплект), «.СО» (спецификация).
- **Ведомость** — Ведомость рабочих чертежей (форма 1), ведомость ссылочных и прилагаемых документов (форма 2).
