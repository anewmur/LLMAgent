# Таблица требований: где реализовано и как проверяется

Формулировки требований — в `docs/requirements.md`, цитаты из стандартов — в `docs/normative_basis.md`. Имена проверок — строки таблицы «Автоматические проверки готовых файлов» в `output/check_report.md` (`stamp_*`, `pdf_*`, `*_pipe_label` — по одной строке на лист). Тесты запускаются командой `pytest`. Строки с пометкой «(уточнить после правок)» описывают код на 09.11.2026 и могут измениться.

Учтённые редакции: ГОСТ Р 21.101-2026 (поправка ИУС 11-2026 известна, но текст не получен — это записано в ограничениях отчёта); ГОСТ 21.704-2011 с Изменением № 1; ГОСТ 21.110-2013; ГОСТ 21.206-2012; тестовое задание.
