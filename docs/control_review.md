# Проверка сессионного выпуска, 06.11.2026

## Состояние и выпуск

`RouteSession` один раз загружает начальный проект. Все инструменты диалога
работают с ним в памяти. Успешный `update_point` проверяет новые данные,
выпускает комплект и только после успеха принимает проект и запись истории.
`z` соответствует отметке оси трубы. Непереданное поле сохраняется;
явный `null` проверяется как удаление значения.

Комплект находится прямо в `output/`: четыре SVG, CSV спецификации,
`check_report.md`, пять PDF в `pdf/` и `changes.md` при наличии изменений.
Сценарные каталоги, снимки входа и манифест не создаются. Допущения и ограничения
включены в отчёт о проверках. При выходе дополнительного сохранения нет.

## Проверенные случаи

- Сессия начинается с трассы 360 м, без `changes.md`.
- P5 X=300: длина 380 м, участок P4–P5 100 м, количество трубы 380 м.
  Перечень содержит изменённую координату, общую длину трассы и четыре перевыпущенных листа.
- Несколько успешных правок накапливаются по порядку. Новый запуск с исходным
  JSON возвращает начальный проект и удаляет прежний перечень после успешного выпуска.
- Удаление отметки P3 через `z=null` отклоняется валидатором.
- Конфликт материала трубы с описанием объекта отклоняется той же полной проверкой.
- Для обоих отказов проверены неизменность проекта, истории и байтов файлов;
  генератор вообще не вызывается. Ошибка передаётся модели для уточняющего вопроса.
- Правка числовой отметки оси проверена отдельно: в перечне только изменённая отметка
  и все четыре перевыпущенных листа; координаты, общая длина и количество трубы сохраняются.
- Входной `input/input.json` не изменяется; чтение изменённого снаружи файла
  не подменяет текущий проект уже работающей сессии.

## Просмотр

Планы и профили 360 и 380 м отрисованы из PDF в `tmp/previews/`.
План 380 м занимает 300 мм по X, профиль — 190 мм по пикетам.
Оба помещаются на A3. Проверены подписи, пикеты, разделители уклонов и основная надпись.

Все 97 тестов проходят. Проверки выполняются в `tempfile`/`tmp_path`.
Диалоговые тесты используют имитацию API модели; реальный сетевой запрос не запускался.
В рабочем `output/` оставлен результат успешной правки P5 на X=300.

Полное соответствие строительной РД не заявляется. Ограничения приведены
в `check_report.md`; нормативные источники и цитаты — в `docs/normative_basis.md`.
